## Media rules

| Pravidlo | Co se mění a proč |
| --- | --- |
| `min-width` | Při 40 em se navigace řadí vedle sebe a od 60 a 80 em přibývají sloupce projektů, aby se využil prostor na širší obrazovce. |
| `prefers-color-scheme: dark` | Tmavá paleta se použije podle nastavení systému a zachová čitelnost textu i odkazů. |
| `prefers-contrast: more` | Černá a bílá, silnější okraje a podtržené odkazy usnadňují rozlišení textu a prvků v obou barevných schématech. |
| `prefers-reduced-motion: reduce` | Vypne animace karet, přechod odkazů a plynulé posouvání, aby se stránka zbytečně nehýbala. |
| `prefers-reduced-transparency: reduce` | Karty dostanou plnou barvu a rozostření i přechod v pozadí se vypnou, aby pozadí zůstalo jednolité. |
| `forced-colors: active` | Systémové barvy určují text, odkazy, okraje a fokus, aby byly prvky vidět v uživatelově paletě. |
